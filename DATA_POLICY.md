# Data policy

All cities, rents, and hedonics in this repository are constructed.

There is no ACS extract, no transaction tape, and no school-district file. `amenity_shock()` uses *w* = 1, *N* = 1, *S0* = 0.2, *S1* = 0.5. The hedonic demo draws NumPy normals. Do not add a Census API client. If a later experiment uses a public sample of rents, record licence, retrieval date, and that the file is an illustration, not a finding about that place.
